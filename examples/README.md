# Examples Directory

This directory contains example implementations and reference code for the AI-IoT Hub.

## Example Implementations

### UI Examples
- `textual_hub.py` - Rich terminal UI using Textual library

### CodeAgent Examples
- `codeagent_direct_file_access.py` - Direct file access patterns with CodeAgent
- `intelligent_docs_workflow.py` - Intelligent document processing workflow
- `llm_native_document_processing.py` - LLM-native document processing

### Discovery Examples
- `real_device_discovery.py` - Real-world device discovery implementation

## Usage

These examples serve as:
- **Reference implementations** for common patterns
- **Starting points** for custom integrations  
- **Educational material** to understand system architecture
- **Testing grounds** for new features

## Running Examples

From the project root:

```bash
# Terminal UI example
python examples/textual_hub.py

# Document processing example  
python examples/intelligent_docs_workflow.py

# Discovery example
python examples/real_device_discovery.py
```

## File Organization

- **UI Examples**: User interface implementations
- **Agent Examples**: CodeAgent usage patterns and workflows
- **Discovery Examples**: Device discovery and network scanning
- **Integration Examples**: Third-party service integrations
